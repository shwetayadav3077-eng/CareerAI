CareerAI360 – AI Skill-Gap Detector and Career Guidance System

Discover Your Skills. Identify Your Gaps. Build Your Career.

CareerAI360 is a web-based career guidance platform designed to help students identify their skills, understand skill gaps, explore career opportunities, and follow a structured learning roadmap.

✨ Key Features

- 📊 **Dashboard:** View career development information.
- 💻 **Skills Management:** Add and manage technical skills.
- 🎯 **Skill Gap Analysis:** Identify skills that need improvement.
- 💼 **Career Exploration:** Explore suitable career options.
- 📚 **Course Recommendations:** Discover courses related to your skills.
- 🗺️ **Learning Roadmap:** Follow learning steps and track progress.
- 👤 **User Profile:** Manage profile information.

Run the Project Locally

Requirements

- Python
- MySQL Server
- Visual Studio Code (recommended)

 Installation

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Create and activate a Python virtual environment.
4. Install the required packages:


   pip install -r requirements.txt


5. Configure your database connection and create the required tables.
6. Start the application:

  
   python app.py
  

7. Open your browser and visit:

   `http://127.0.0.1:5000`

 Security

- Never publish database passwords or secret credentials.
- Use environment variables to store database connection details.
- Protect user account information.
